# 🚀 Sito Web CV & Portfolio - Studente 5° Anno Informatica

Questo progetto è un sito web personale, portfolio e curriculum vitae moderno, reattivo ed elegante, creato su misura per uno studente all'ultimo anno (5ª superiore) con competenze in **C++, Java, HTML, CSS e JavaScript**.

---

## 📂 Struttura del Progetto

```text
📁 byanti/
├── 📄 index.html      # Struttura semantica della pagina e contenuti
├── 🎨 style.css       # Stili moderni, animazioni, temi Scuro/Chiaro e layout responsive
├── ⚡ script.js       # Logica interattiva (filtri progetti, popup modale, tema, form)
└── 📖 README.md       # Questa guida rapida
```

---

## ✨ Funzionalità Incluse

1. **Tema Scuro / Chiaro:**
   - Pulsante toggle in alto a destra con memorizzazione automatica della scelta (`localStorage`).
2. **Hero Section Dinamica:**
   - Animazione di digitazione (typing effect) per i ruoli ("Sviluppatore Software", "Programmatore C++ & Java", ecc.).
   - Card terminale con finto codice C++ per un tocco tecnico immediato.
3. **Presentazione Personale (Chi Sono):**
   - Box dettagliati su competenze algoritmiche, logica OOP, sviluppo web e attitudine al lavoro di squadra.
4. **Competenze Tecniche (Skills):**
   - Card dedicate per **C++**, **Java**, **HTML5**, **CSS3**, **JavaScript (ES6+)** e **Strumenti (Git/GitHub, VS Code)** con barre di avanzamento grafiche.
5. **Timeline di Formazione:**
   - Il percorso del 5° anno (preparazione Maturità), gli anni del triennio e le esperienze di PCTO / Laboratorio.
6. **Portfolio Progetti con Filtri Interattivi:**
   - Filtra i progetti con un click: `Tutti`, `C++`, `Java`, `Web`.
   - Modale popup per visualizzare i dettagli approfonditi e gli obiettivi tecnici di ciascun progetto.
7. **Pronto per la Stampa / Esportazione PDF:**
   - Cliccando su *"Stampa / PDF"* oppure premendo `Ctrl + P`, il sito si adatta automaticamente per essere stampato o salvato come curriculum cartaceo pulito ed elegante.
8. **Modulo di Contatto & Social:**
   - Form con validazione interattiva e link diretti a Email, GitHub e LinkedIn.

## 🛠️ Come Personalizzare i Tuoi Dati

Tutti i punti da modificare sono contrassegnati nei file con il commento `<!-- MODIFICA QUI -->`. 
In particolare in [index.html](file:///c:/Users/singh/OneDrive/Desktop/byanti/index.html):

- **Nome e Cognome:** Sostituisci `"Il Tuo Nome"` nel titolo della Hero (riga ~79).
- **Email:** Sostituisci `tuaemail@esempio.com` con la tua vera email.
- **Scuola / Città:** Inserisci il nome della tua scuola e la tua città nella sezione Formazione e Chi Sono.
- **Link Social / GitHub:** Sostituisci `github.com/tuo-username` e `linkedin.com/in/tuo-profilo` con i tuoi link reali.
